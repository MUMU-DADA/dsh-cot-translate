# 里程碑与路线图（Roadmap）

> 记录各阶段里程碑的完成情况与验收标准。

## 已完成里程碑

### ✅ M0 脚手架与工程化基础（2026-10-19）
- 建立目录结构、`package.json`（`dsh.bundle.patch` + `dsh.client`）、`cordis.patch.yml` 及 esbuild 构建脚本。
- `npm run build` 产出服务端 `lib/index.js` 与浏览器端 `lib/client.js`。

### ✅ M1 / M1b 展开思考块就地双语对照面板（2026-10-19）
- 核实 `conversation.chat.node` 为替换语义，定案采用 **`MutationObserver` 观察展开态 + 就地 DOM 注入双栏面板**（ADR-014）。
- 原文优先从 `ChatNodeStore` 数据层读取，确保围栏代码完整进入剥离器。
- 左原文、右译文逐段对齐，鼠标悬停整行联动高亮，窄窗口（`< 520px`）自动上下堆叠。
- 逐段独立请求（2 路并发），先回先显；流式输出尾巴设置 400ms 稳定防抖窗口。
- 折叠或卸载时自动移除面板与标记，无损恢复原始界面。

### ✅ M2 服务端翻译接口与本地 `llama.cpp` 集成（2026-10-20）
- 同源路由 `/_cotx/*`、入参边界校验、本机访问保护（`connection.requestRejection`）。
- 默认使用免安装、无 GUI 的 `llama.cpp` `llama-server`（Vulkan 后端，按需无窗口拉起），支持腾讯 **Hy-MT2** GGUF 模型。
- 保留可选 Ollama 适配器与免费 Google 翻译兜底；全部失败时安全退化显示原文（fail-open）。

### ✅ M3 客户端代码保护与分批流水线（2026-10-20）
- 分段原位保留代码块、行内代码、URL、文件路径与 `fn()` 调用（不使用易损坏的占位符）。
- 长段落按句子切分并分批请求，客户端 + 服务端多级缓存。

### ✅ M4 设置页、模型管理与磁盘缓存（2026-10-20）
- 注册「设置 → 思维链翻译」页面：总开关、半自动/自动时机切换、33+ 种译文目标语言选择（默认跟随客户端语言）。
- 内置 1.8B Q4_K_M 兜底模型（不可删）+ 在线下载/更新/删除 1.8B Q8_0 与 7B Q4_K_M 模型。
- 支持借用当前对话 API 模型翻译、本地模型速度测试、本地服务端口配置（默认 `28457`）与端口占用实时检测。
- 50MB 磁盘译文缓存（只存译文，原文不落盘，支持一键清理）。
- 设置页与文档完整展示模型与第三方组件许可证（`THIRD_PARTY_LICENSES.md`）。

### ✅ M4.5 插件界面多语言（i18n）与多语言文档（2026-10-20）
- 抽取全量 62 个 UI 文案 key 至 `src/client/locales/<locale>.json`，服务端改为只返回 `labelKey` / `noteKey` / `errorCode`。
- 完成 **9 种 UI 语言 100% 翻译**：简体中文（`zh`）、English（`en`）、繁體中文（`zh-Hant`）、日本語（`ja`）、한국어（`ko`）、Français（`fr`）、Deutsch（`de`）、Español（`es`）、Русский（`ru`）。
- 切换 DSH 语言时设置页与双语面板实时刷新，数字与容量使用 `Intl.NumberFormat` 本地化。
- 提供中、英、繁中、日四语 `README` 及双语架构与许可证文档。

## 后续可选计划（M5 / M6）

- ⬜ **7B 模型深度评测**：对比 1.8B 与 7B 在多语言长推理下的译文质量与延迟。
- ⬜ **全新 Profile 安装验收与发布准备**：在干净环境中验证完整安装 → 翻译 → 卸载流程，并评估 npm 发布流程。

## 明确不做（Non-Goals）

- **不靠提示词强迫模型用中文思考**：容易降低模型推理质量，且非显示层职责（ADR-001）。
- **默认不翻译最终回答**：插件专注于解决“英文思考过程难读”的痛点（ADR-010）。
- **不部署到缺乏 AVX 指令集的低功耗边缘设备**：推理速度不足（ADR-005）。
- **不使用尚未合并入主线的 1.25bit STQ 极端量化格式**（ADR-009）。
